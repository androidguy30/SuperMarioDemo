Unity Architecture

Full Unity project included with C# scripts: PlayerController, GameManager, EnemyController, LevelGenerator, CameraFollow, and more.

WebGL Build

HTML5 Canvas demo mirrors what Unity's WebGL build pipeline produces. Custom WebGL template included in the project.

Classic Gameplay

Features classic Mario mechanics: variable-height jumping, enemy stomping, brick breaking, coin collecting, and flagpole finish.

Open Source

Open the Unity project in Unity 2021+ to customize, add sprites, audio, and build for any platform including WebGL.
